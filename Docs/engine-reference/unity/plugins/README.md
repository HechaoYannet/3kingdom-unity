# Unity 2022 LTS Plugin Reference

**Note:** The plugin files in this directory were originally created for Unity 6.3 LTS documentation.

**Current Project:** This project uses Unity 2022 LTS (Tuanjie Engine 1.5.3 compatible).

## Plugin Version Differences:

### Addressables
- **Unity 6.3 LTS**: Addressables 2.0+
- **Unity 2022 LTS**: Addressables 1.19+
- **Note**: API differences may exist between versions

### Cinemachine
- **Unity 6.3 LTS**: Cinemachine 3.0+
- **Unity 2022 LTS**: Cinemachine 2.8+
- **Note**: Check version-specific API documentation

### DOTS/Entities
- **Unity 6.3 LTS**: Entities 1.3+ (production-ready)
- **Unity 2022 LTS**: Entities 0.51+ (preview)
- **Important**: Major API differences, not production-ready in 2022 LTS

## Usage Guidance:

When consulting these plugin files:
1. Check the plugin version compatibility
2. Verify APIs exist in Unity 2022 LTS versions
3. Be aware that some features may be Unity 6.x only

For accurate information:
- Check Package Manager for installed versions
- Refer to version-specific documentation
- Use WebSearch for specific version questions

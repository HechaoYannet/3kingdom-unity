# Unity 2022 LTS Module Reference

**Note:** The module files in this directory were originally created for Unity 6.3 LTS documentation.

**Current Project:** This project uses Unity 2022 LTS (Tuanjie Engine 1.5.3 compatible).

**Important:** The information in these module files may reference Unity 6.3 LTS features, APIs, or deprecations that do NOT apply to Unity 2022 LTS.

## Key Differences to Note:

1. **Input System**: Legacy Input Manager (`Input.*`) is NOT deprecated in Unity 2022 LTS
2. **DOTS/Entities**: Is a preview package, not production-ready
3. **UI Toolkit**: Runtime support is preview, UGUI is primary runtime UI
4. **C# Version**: C# 8.0 (.NET Standard 2.1), not C# 9+

## Usage Guidance:

When consulting these module files:
- Verify API compatibility with Unity 2022 LTS
- Check if features mentioned are available in 2022 LTS
- Be aware that deprecation warnings may be for Unity 6.x only

For accurate Unity 2022 LTS information:
- Refer to Unity 2022.3 documentation
- Use WebSearch for specific API questions
- Assume standard Unity 2022 LTS behavior unless otherwise noted
